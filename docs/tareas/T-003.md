# T-003 — Persistencia y CRUD de análisis con carga de imagen

**Objetivo:** que un análisis se pueda crear subiendo una foto, listar, consultar, renombrar y eliminar a través de la API, persistido en PostgreSQL y con la imagen en disco. Cubre HU-01 y la base de HU-10.

**Lee antes:** CLAUDE.md, docs/arquitectura.md, docs/dominio.md, docs/api.md (sección "Análisis (CRUD)" y "Formato de error").

## Alcance

### 1. Puertos (`app/aplicacion/puertos.py`)
`RepositorioAnalisis`, `AlmacenImagenes` y `Segmentador` como en docs/arquitectura.md (Segmentador solo se declara), más un puerto nuevo:
```python
class InspectorImagenes(Protocol):
    def inspeccionar(self, contenido: bytes) -> tuple[str, int, int]: ...  # (formato "JPG"|"PNG", ancho_px, alto_px)
```
Motivo: detectar formato y dimensiones requiere Pillow, que no puede estar en dominio ni aplicación. El formato se detecta por el contenido del archivo, no por la extensión ni por el content-type. Si Pillow no reconoce el archivo o es otro formato, el adaptador lanza `FormatoImagenNoValido`.
Agrega este puerto a docs/arquitectura.md.

### 2. Casos de uso (`app/aplicacion/casos_de_uso/`)
Uno por módulo, reciben los puertos por constructor:
- `CrearAnalisis(nombre, contenido)`: inspecciona → guarda la imagen → crea el agregado → lo persiste. Si falla la persistencia, elimina la imagen guardada.
- `ListarAnalisis()`, `ObtenerAnalisis(id)`, `RenombrarAnalisis(id, nombre)`, `EliminarAnalisis(id)` (borra también la imagen), `ObtenerImagen(id) -> (contenido, formato)`.
- Id inexistente → `AnalisisNoEncontrado`. Nombre vacío o de más de 150 caracteres → `DatosNoValidos(ErrorDominio)` (nuevo, en errores.py; 422).

### 3. Persistencia (`app/adaptadores/salida/persistencia/`)
- Tablas SQLAlchemy según el modelo de datos del hito 3: `analisis` (con los datos de la imagen), `calibracion` (PK = FK analisis_id), `region_excluida` (PK = FK, polígono en JSONB), `fragmento` (polígono en JSONB). Sin `usuario` ni `rango_tamano` todavía. Borrado en cascada desde `analisis`.
- Las clases del dominio NO se mapean con el ORM: usa modelos de tabla propios y funciones de conversión dominio ↔ tabla.
- `RepositorioPostgreSQL.guardar` persiste el agregado completo (reemplaza calibración, región y fragmentos del análisis).
- Primera migración de Alembic que crea estas tablas.
- El contenedor backend ejecuta `alembic upgrade head` antes de iniciar uvicorn (script de entrada). Esto resuelve el pendiente de T-001.

### 4. Almacenamiento (`app/adaptadores/salida/almacenamiento/`)
`AlmacenArchivosLocal` en `RUTA_IMAGENES`: nombre de archivo `<uuid>.<jpg|png>`; guarda la ruta relativa. `InspectorImagenesPillow` en el mismo paquete o en uno propio.

### 5. API (`app/adaptadores/entrada/api/`)
- Mueve la ruta `/salud` de main.py a un router aquí.
- Router de análisis con las rutas de docs/api.md "Análisis (CRUD)" y los esquemas `AnalisisResumen` y `AnalisisDetalle` (en detalle, calibracion y region_excluida pueden venir null; fragmentos lista vacía).
- Manejador global que traduce cada `ErrorDominio` a su HTTP y `{codigo, detalle}` según docs/api.md.
- Imagen de más de 20 MB → 413 `ARCHIVO_DEMASIADO_GRANDE` (agrégalo a docs/api.md).
- `main.py` solo compone: instancia adaptadores y los inyecta en los casos de uso (dependencias de FastAPI).

## Pruebas
- Unitarias de cada caso de uso con fakes en memoria (`tests/unit/aplicacion/fakes.py`): repositorio, almacén e inspector falsos. Incluye el caso de rollback de la imagen si falla el repositorio.
- Integración de la API (`tests/integracion/test_api_analisis.py`) sobreescribiendo las dependencias con los fakes: crear (201), listar, obtener, renombrar, eliminar (204), obtener imagen, formato no válido (415), id inexistente (404), nombre vacío (422).
- Integración del repositorio (`tests/integracion/test_repositorio_postgresql.py`) contra PostgreSQL real usando la variable `TEST_DATABASE_URL`; si no está definida, las pruebas se marcan como omitidas (skip) con un mensaje claro. Debe cubrir guardar y recuperar un agregado con calibración, región y fragmentos (los fragmentos se crean con el dominio directamente).
- Integración del inspector con dos imágenes pequeñas generadas en la prueba con Pillow (JPG y PNG) y un archivo de texto (rechazado).
