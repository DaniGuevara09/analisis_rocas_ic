# T-009 — Cierre de requisitos: CSV, rangos configurables, despliegue sin pasos manuales

> **Redactada a pedido de Bibian Corredor**, para dejar el sistema funcionando según docs/requisitos.md. Camilo la revisa.

**Objetivo:** completar los requisitos pendientes del núcleo y del complementario RF-14, y dejar listo el espacio para instalar el modelo entrenado.

## Alcance

1. **RF-09 / HU-09 — Exportar CSV:** ruta `GET /api/analisis/{id}/resultados.csv` y botón en la pantalla de Resultados.
   - El CSV incluye datos del análisis, indicadores, supuestos (RNF-07), rangos, curva y una fila por fragmento.
   - Formato para Excel en español: separador `;`, coma decimal y UTF-8 con BOM.
2. **RF-14 — Configurar rangos de tamaño y colores:**
   - **Dominio:** `ConfiguracionRangos`, con modo relativo (% pasante) o absoluto (mm), de 2 a 8 rangos, nombres y colores.
   - **Persistencia:** tabla `configuracion` (migración 0002).
   - **API:** `GET`, `PUT` y `DELETE /api/configuracion/rangos`.
   - **Frontend:** pantalla `/configuracion`.
   - Los resultados, el editor, el CSV y el PDF usan los colores configurados.
3. **RNF-06:** `docker compose up` funciona sin crear el `.env` (`env_file` opcional y valores por defecto). Se agrega `PUERTO_WEB`.
4. **Espacio para el modelo:**
   - `backend/modelos/README.md`.
   - `GET /api/salud` informa `modelo_disponible`.
   - El editor avisa y desactiva *Segmentar con IA* si no hay modelo.
5. **Documentación:**
   - `docs/GUIA_DEL_SISTEMA.md`: flujo detallado y todos los comandos de prueba.
   - `scripts/prueba_humo.ps1`: prueba de punta a punta por la API.

## Decisiones (decidido con Bibian, confirmar)
- RF-13 (usuarios y roles) **no** se implementa en esta tarea.
- La configuración de rangos es **global**: se aplica a todos los análisis. No se guarda por análisis.
- El color de cada rango es un dato de configuración en formato `#rrggbb`. El frontend lo recibe de la API, en lugar de los tokens `--color-rango-*` que se eliminaron.
