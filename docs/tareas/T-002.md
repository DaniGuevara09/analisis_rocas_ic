# T-002 — Dominio y cálculo granulométrico (TDD)

**Objetivo:** implementar la capa de dominio completa del Sprint 2 y la calculadora granulométrica, con pruebas unitarias escritas antes del código. Es la base de las "pruebas unitarias preliminares" del hito 4.

**Lee antes:** CLAUDE.md, docs/dominio.md (fuente de verdad de fórmulas y reglas), docs/requisitos.md (RF-02, RF-03, RF-07, RNF-07).

## Alcance
Solo `backend/app/dominio/` y `backend/tests/unit/dominio/`. Solo librería estándar de Python (math, dataclasses, enum, uuid, datetime). No uses numpy.

1. `errores.py`: las excepciones de docs/dominio.md, con una clase base `ErrorDominio`.
2. `modelo.py`:
   - `Punto`, `Poligono` (≥ 3 puntos; `area()` con fórmula del zapato en valor absoluto; `centroide()`; `contiene(punto)` con ray casting), `Imagen` (formato JPG/PNG), `Calibracion` (`factor_mm_por_px()`), `RegionExcluida`, `Fragmento` (`area_px()`, `diametro_equivalente_mm(factor)`), `EstadoAnalisis`, `OrigenFragmento`, `ResultadoGranulometrico`, `PuntoCurva`.
   - Objetos de valor inmutables (`@dataclass(frozen=True)`) con validación en `__post_init__`.
   - `Analisis` (agregado) con: `crear(nombre, imagen)`, `calibrar(inicio, fin, longitud_mm)`, `excluir_region(poligono)`, `quitar_region_excluida()`, `registrar_fragmentos(poligonos, origen)`, `agregar_fragmento(poligono)`, `eliminar_fragmento(id)`, `calcular_resultado()`.
   - Reglas de estado de docs/dominio.md: registrar fragmentos sin calibración lanza `EscalaNoCalibrada`; los fragmentos con centroide dentro de la región excluida no se registran; recalibrar no cambia el estado SEGMENTADO.
   - Unir y dividir fragmentos quedan FUERA de alcance (Sprint 3).
3. `granulometria.py`: funciones puras `factor_mm_por_px`, `area_mm2`, `diametro_equivalente_mm`, `ponderacion` (provisional: d³, aislada en una sola función), `curva_granulometrica`, `percentil_dx` (interpolación lineal), `indice_uniformidad_n` (Rosin-Rammler por mínimos cuadrados con puntos 0 < P < 1) y `calcular(diametros_mm) -> ResultadoGranulometrico`.

## Casos de prueba obligatorios (valores calculados a mano)
Tolerancia: 1e-3 salvo que se indique otra.
- Factor: inicio (0,0), fin (300,400), longitud 250 mm → distancia 500 px → 0.5 mm/px.
- Calibración no válida: longitud 0, longitud negativa y puntos coincidentes lanzan `CalibracionNoValida`.
- Área: cuadrado de 10×10 px → 100 px²; el mismo cuadrado en sentido horario y antihorario da el mismo valor.
- Polígono con 2 puntos o con área 0 (puntos colineales) lanza `PoligonoNoValido`.
- Área real y diámetro: cuadrado de 100 px² con factor 0.5 → 25 mm² → d_eq = 5.642 mm.
- Curva con diámetros [10, 20, 30] mm (pesos 1000, 8000, 27000): P = 2.778 %, 25.000 %, 100.000 %.
- Dx sobre esa curva: D20 = 17.750 mm, D50 = 23.333 mm, D90 = 28.667 mm. Un percentil por debajo del primer punto devuelve el diámetro menor.
- Rosin-Rammler: con x = [50, 100, 200] mm y P(x) = 1 − exp(−(x/100)^1.5), `indice_uniformidad_n` devuelve 1.5 (tolerancia 1e-9).
- Menos de 2 puntos válidos para el ajuste lanza `DatosInsuficientes`. `calcular([])` también.
- Exclusión: región = cuadrado (0,0)–(100,100); un fragmento con centroide en (50,50) no se registra y uno con centroide en (200,200) sí.
- Estados: registrar fragmentos sin calibrar lanza `EscalaNoCalibrada`; tras calibrar pasa a CALIBRADO; tras registrar, a SEGMENTADO; recalibrar un análisis SEGMENTADO lo deja en SEGMENTADO.
- Imagen con formato "GIF" lanza `FormatoImagenNoValido`.
