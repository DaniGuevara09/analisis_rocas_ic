# Reporte T-012 — Correcciones de usabilidad

- **Fecha:** 2026-11-20
- **Estado:** ✅ Implementada, pendiente de revisión. Solo cambia el frontend; la API y el dominio no cambian.

## 1. Defectos: causa y corrección

| Defecto | Causa encontrada | Corrección |
|---|---|---|
| Calibrar de nuevo la escala | Se podía, pero no era evidente: el botón seguía diciendo "Calibrar" y desde el editor solo había "Atrás" | El botón pasa a "Recalibrar". Aparece un aviso si la línea o la longitud cambiaron sin aplicarse. El editor tiene **Recalibrar** junto a la escala y avisa que se recalculan los tamaños |
| Más opciones de longitud de objetos | Solo había un campo numérico | Objetos frecuentes: regla de 30 y 50 cm, flexómetro de 1 m, mira de 2 m. Se puede escribir cualquier otro valor |
| Opciones de unidad de la longitud | El campo aceptaba solo mm | Selector **mm / cm / m**, con la equivalencia en mm. Acepta coma decimal. Avisa si el valor es menor de 5 cm o mayor de 3 m |
| Exclusión: ¿es necesaria? / no funcionó en el paso siguiente | Había que pulsar *Cerrar región* **y después** *Guardar región*. Si se olvidaba el segundo botón, la región no llegaba al servidor y el objeto se seguía contando | **Cerrar y guardar región** en un solo paso. Texto "¿Es necesario?". Confirmación al descartar o eliminar la región. No se puede continuar mientras se está delimitando. El editor indica si hay una región activa |
| Control de calidad, ¿funciona? | No: eran 3 casillas que solo sumaban un contador | Se quitó. Queda una línea de ayuda: Dividir, Dibujar o Eliminar |
| Deshacer un punto mal puesto | Solo existía *Esc*, que borraba todo el trazo | Botón **Quitar punto**, Retroceso o Ctrl+Z mientras se traza; sirve para Dibujar y para el corte libre |
| Mensaje de espera al delimitar | El estado "Guardando..." estaba en el panel lateral | Aviso con indicador giratorio sobre el lienzo: *Guardando el cambio y recalculando tamaños...* o *Segmentando...* |
| Más opciones para dividir | Solo línea recta de 2 clics | Selector **Línea recta / Corte libre**. El corte libre sigue una grieta con varios clics. Nueva función `dividirConTrazo`, con pruebas |
| No se diferencian tamaños | Paleta de 5 azules (corregida en T-011) y relleno con 30 % de opacidad | Relleno al 45 %, con los colores nuevos de T-011. Los colores aparecen desde 3 fragmentos |
| Error en el campo del nombre | El campo decía "(opcional)", pero el servidor rechaza un nombre vacío. El error salía lejos del campo y después de subir la foto | Nombre obligatorio, validado al salir del campo y al continuar. Error debajo del campo, en rojo, con `aria-invalid`. Se propone el nombre del archivo |

**Sobre las dos secciones de las capturas**
- "Control de calidad" **no hacía nada**, por eso se quitó.
- "Exclusión del objeto de referencia" **sí funcionaba**, pero era fácil que la región no se guardara. Se mejoró en lugar de quitarla, porque sin ella el objeto de escala se cuenta como roca.
